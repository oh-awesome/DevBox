## 文档维护规则

1. 新增文档先在本索引登记（名称 + 一句话内容）；
2. 文档只描述当前状态：功能是否实现在《产品需求文档》的模块规格与路线图中表达，不另立变更记录；版本演进统一记入根目录 ReleaseNote.md；
3. 修改代码导致文档失实时同步更新文档，头部的基线版本号一并调整。
