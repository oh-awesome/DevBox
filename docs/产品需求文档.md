# DevBox 产品需求文档

> 基线：v2.0.0（2026-11）。本文档定义 DevBox 的产品定位、功能范围与交互要求。
> 配套文档：《架构设计》（实现结构）、《UI设计规范》（视觉与交互细节）、《安装协议与制品规范》（制品方契约）、《权限说明》（权限用途）。

## 1. 产品概述

### 1.1 定位

DevBox 是 HarmonyOS PC 上的开发者环境管理工具：开发者在图形界面里完成开发环境的搭建、配置、维护与排障，替代散落在各处的手工命令。

产品目标：一台新的鸿蒙 PC，从开箱到"能编译运行第一个程序"，全程只在 DevBox 里点击完成，且每一步都知道系统发生了什么。

### 1.2 核心能力

| 能力 | 说明 |
|---|---|
| 语言环境管理 | Python、Java、Rust、Node.js、Lua、Perl、Go、PHP 八种运行时的安装、多版本共存、活跃版本切换、卸载 |
| 包与工具管理 | 通用开发工具（60+ 鸿蒙化 CLI）、HarmonyBrew（鸿蒙版 Homebrew）、Conan（C/C++ 组件库）三类来源的搜索、安装与升级 |
| 环境配置管理 | PATH 等环境变量的图形化编辑（~/.zshrc / ~/.bashrc），pip / npm / Maven / cargo / GOPROXY 等镜像源配置 |
| 环境健康维护 | 环境总览的状态面板与环境体检，问题发现与修复引导 |

### 1.3 目标用户

- **鸿蒙应用/原生开发工程师（主力）**：熟悉终端，痛点是环境搭建碎片化、依赖安装繁琐、排障无工具；
- **从 Linux/macOS 迁移的开发者**：期望 brew / nvm / sdkman / rustup 一类生态工具的图形化等价物；
- **团队环境标准化负责人**：快速给多台机器配置一致环境。

### 1.4 运行环境与系统前置

- HarmonyOS PC（2in1），键鼠 + 触摸双输入；独立窗口，最小 800×600，支持最大化与缩放；
- 应用隐藏系统窗口装饰栏（`setWindowDecorVisible(false)`）；
- 使用 DevBox 安装的开发工具属非应用市场二进制，依赖两项系统设置：
  - **开发者模式**（设置 → 关于本机，连点 7 次版本号）；
  - **运行来自非应用市场的扩展程序**（设置 → 隐私和安全 → 高级）。
  应用不拦截使用，在总览页与"关于"页提供状态提示和直达系统设置的教程引导。

## 2. 信息架构

### 2.1 导航结构

左侧固定边栏（图标 + 文字，底部全局反馈入口），右侧内容区。

| 分组 | 菜单 | 说明 |
|---|---|---|

| 实用工具 | 通用工具 | 60+ 鸿蒙化 CLI 工具的目录与安装 |
| | 环境变量 | shell 配置文件的结构化编辑 |

### 2.2 内容区顶栏

| 元素 | 行为 |
|---|---|
| MCP 状态胶囊 | 显示 MCP 服务启停状态，点击打开 MCP 管理弹窗（服务开关、接入配置展示与复制） |
| 任务队列按钮 | 显示排队任务数角标，点击展开队列面板（进行中/排队任务、出队与取消） |
| 手动刷新 | 触发当前页数据重载 |
| 主题切换滑块 | 明/暗双模式即时切换并持久化 |

### 2.3 长任务模式

所有安装、卸载、升级、切换操作统一走任务队列异步执行：

- **分步进度**：步骤名 + 进度百分比 + 下载量/总量，行内进度条展示；
- **可取消**：执行中随时可取消，下载支持断点续传（重试从断点继续）；
- **排队**：任务进入三级队列（交互优先级分组），顶栏角标实时反映队列长度；
- **失败处理**：失败定位到步骤并给出原因，支持重试与复制日志；
- **完成反馈**：成功提示 + 后续引导（重开终端生效等）。

### 2.4 首次启动

首次打开弹出使用提示：安装完成的环境变量需重启设备（或重开终端应用）后生效；可勾选"不再提示"。提示中附环境准备指南入口（开发者模式与非应用市场扩展程序的系统设置教程）。

## 3. 模块功能规格

### 3.1 环境总览（默认首页）

回答"我的环境现在什么状态"，并为新用户提供快速开始。

| 功能 | 说明 |
|---|---|
| 产品介绍区 | 应用定位的概述展示 |
| 快速开始 | 未安装任何运行时时展示套件卡片（C/C++、Java、Rust、Node.js、基础命令等），一键安装并自动配置；随安装情况自动过渡到状态视图 |
| 模块网格 | 每个语言/工具一个卡片：当前活跃版本（未安装则显示引导）、PATH 是否生效、来源；点击进入对应模块 |
| 环境体检 | 运行时 `--version` 实测、devbox bin 目录在 PATH、镜像源连通性、磁盘与缓存占用、注册表一致性；输出问题列表，每项带"去修复"跳转 |
| PATH 修复 | 对缺失的 zshrc 标记块提供一键补写 |

交互要求：卡片状态色语义统一——正常（绿）/警告（黄）/异常（红）/未安装（中性）；体检结果可整体复制。

### 3.2 语言运行时管理（八个语言页同构）

八个语言页（Python、Java、Rust、Node.js、Lua、Perl、Go、PHP）共用一套交互模式：学会一个就会用所有。

**运行时管理（公共能力）**：

| 功能 | 说明 |
|---|---|
| 版本列表 | 可装版本来自制品仓 manifest 索引（含体积、发布信息）；已装版本显示安装时间与"活跃"标记 |
| 安装 | 走安装协议执行器：下载（断点续传）→ SHA256 校验 → 解压 → 版本目录与 current 链接 → PATH 标记块 → 终端验证；全程分步进度可取消 |
| 切换活跃版本 | 更新 current 链接与 PATH 标记块，提示重开终端生效 |
| 卸载 | 删除版本目录；卸载活跃版本自动切换到剩余最高版本，无剩余版本时清理链接与标记块 |
| 就绪探测 | 页面进入时探测已装版本与 PATH 生效状态 |

**各语言包族**（manifest 中的 runtime 族）：python、BiShengJDK（Java）、rust、node、lua、perl、php、go。

**语言特有 Tab**：

| 语言 | Tab 结构 | 特有功能 |
|---|---|---|
| Python | 运行时 / 镜像管理 / 包管理 | pip 包搜索（OHPCD 适配源）、安装/卸载/已装列表；pip 源 4 预设 + 自定义源（写 ~/.pip/pip.conf） |
| Node.js | 运行时 / 镜像管理 / 包管理 | npm 全局包列表/安装/卸载；npm 源预设（npmmirror 等）+ scope 私有源（写 ~/.npmrc）；npm ping 连通实测 |
| Java / Rust / Lua / Perl / Go / PHP | 运行时 | 镜像与包生态 Tab 按商用发布范围隐藏（`FeatureScope.ECO_TABS`），页面代码保留 |

Python 包管理前置约束：未装 Python 时包管理 Tab 引导"先安装 Python"并提供跳转。

### 3.3 通用工具

跨语言通用开发工具的统一目录与安装管理。

| 功能 | 说明 |
|---|---|
| Tab 结构 | 软件仓库 / 已安装 |
| 分类目录 | 版本控制、构建系统、编译器工具链、调试与分析、基础命令五类 |
| 工具详情 | 名称、版本、描述、来源标签（Conan / Harmonybrew / 制品仓）、提供的命令清单、依赖说明 |
| 搜索 | 名称/关键字过滤 |
| 安装 | 后端按来源路由（Conan 优先，其次 brew，再次制品仓）；同名命令多来源时提示选择 |
| 已装探测 | `which` 探测系统已有命令，避免重复安装 |
| 开发套件 | 预组合套件一键安装 + 自动配 PATH（C/C++ 桌面 / Java / Rust / Node.js / 基础命令）；套件内容可展开逐项勾选，进度逐工具体现 |

### 3.4 HarmonyBrew

鸿蒙版 Homebrew 的图形化管理，从零安装到日常使用（一键安装流程含 zsh 前置部署）。

| Tab | 功能 |
|---|---|
| 包管理器 | 未安装态：brew 可用性检测 + 介绍 + 一键安装（环境诊断 → zsh/brew 双阶段安装 → update）；已安装态：版本徽章、已装数、磁盘占用、更新 Brew、环境诊断、卸载（危险区二次确认） |
| 软件仓库 | formula 列表（名称/描述/版本/已装标记）、搜索、安装/卸载/重装/详情、推荐包、多 tap 切换 |
| 已安装 | 已装 formula 视图（包/提供命令/版本/安装时间）、行内升级/重装/卸载 |
| 可升级 | outdated 列表与批量升级、批量检查更新 |

执行环境：brew 命令统一经仓库实体 `~/.harmonybrew/Homebrew/bin/brew` 执行（密封 PATH 环境，防工具链互相影子化）；已装/可升级列表按 `list --versions --formulae` 文本解析。

### 3.5 Conan

C/C++ 组件库的发现 → 评估 → 安装 → 升级 → 卸载全生命周期管理。

| Tab | 功能 |
|---|---|
| 包管理器 | Conan 自身的安装管理（依赖 Python，未装时引导跳转 Python 页）与状态概览（版本、远程仓、profile） |
| 软件仓库 | 包列表（分类/搜索/已装过滤）、包详情（依赖关系、构建溯源、测试报告、二进制兼容矩阵）、安装/卸载/仅下载 |

- 目录数据：进程内直连社区 Conan 远程（CDN 兜底），离线缓存降级；
- 安装前置：依赖预检弹窗（将装 X、升级 Y、已满足 Z，冲突红色标注），提供"安装全部（含依赖）/仅主包/取消"三选；
- 卸载：清 wrapper 命令 → 删隔离目录 → 清 conan 缓存 → 更新注册表，确认弹窗列明将移除的命令名。

### 3.6 环境变量

安全地图形化编辑 `~/.zshrc` / `~/.bashrc` 及自定义文件中的 export 变量，不动文件其他内容。

| 功能 | 说明 |
|---|---|
| 文件管理 | 内置 ~/.zshrc、~/.bashrc；可添加自定义文件（显示名 + 路径，配置存沙箱）；移除条目不动磁盘 |
| 文件访问 | 内置 ~/.zshrc、~/.bashrc 凭 READ_WRITE_USER_FILE 直接读写，无授权流程；添加自定义文件（下载等公共目录、用户目录外路径）经系统文件选择器授权并持久化，重启免重复授权 |
| 变量列表 | 解析全部 export；同名多次 export 按 `:` 合并；`$VAR` 自引用解析（模拟 shell 追加语义）；注释/alias/空行原样保留 |
| 变量操作 | 新增、编辑（可重命名）、删除；多值变量（含 `:`）展开子项编辑/排序/删除 |
| 未保存守卫 | 修改高亮、全局未保存指示、切换/刷新前阻断 |
| 保存 | 变量输出到首个 export 行位置（同名多行合并为一行）、非 export 行原样保留、新增变量追加末尾 |
| 多文件同步 | 源 → 多目标，只追加目标缺失的变量（不覆盖不合并），结果明确反馈 |
| 托管块保护 | DevBox 管理的标记块（`# >>> devbox xxx >>>`）只读展示，防止误改破坏联动 |

### 3.7 MCP 服务

应用内置 MCP（Model Context Protocol）服务器，向同设备的外部 AI 应用与开发者工具暴露环境管理能力。

- 传输：HTTP JSON-RPC，监听 `127.0.0.1:18765/mcp`，仅本机访问；
- 工具集：47 个工具，按 L0-L4 分层——L0 环境感知与指导、L1 查询（运行时/包/工具/环境状态）、L2 安装卸载、L3 配置（源/环境变量）、L4 brew 包管理；
- 默认状态：**首次安装不启动**（本地网络服务由用户在 MCP 管理弹窗主动开启；开关持久化，开启后随应用自启；开启同时获得托盘常驻，关闭同时退出托盘）；
- **敏感操作强制设备确认（服务端分类）**：危险类工具（运行时/工具/包的卸载与切换，共 9 个）一经调用即向设备发送确认通知，用户在独立确认小窗中二次确认后才执行（30 分钟超时自动取消）——确认策略由 DevBox 定义，调用方无法绕过；
- 其他约束：确认通知引导（MCP 开启时请求通知授权、弹窗提供直达通知设置的按钮）；安装/升级类操作与 UI 行为一致（一键直装）；
- 接入：MCP 管理弹窗提供标准 JSON 配置片段展示与一键复制。

### 3.8 反馈

边栏底部"反馈"入口，弹窗提交问题：

- 表单：类型（Bug/建议/疑问）+ 标题 + 描述；
- 提交走社区 Issue 接口（见《反馈提交接口文档》），成功后返回 Issue 链接可点击查看；
- 提交前展示隐私声明：反馈将发布到社区公开 Issue，所有人均可见，勿包含个人敏感信息。

### 3.9 关于

- **应用信息**：Logo、名称、版本号（点击展开构建号）、描述；
- **开发者信息**：开发者、官网、隐私政策链接；
- **开源声明**：弹窗展示三方组件许可证（Mulan PSL-2.0 / MIT / 0BSD 等），协议原文折叠展开查看；
- **源码仓库**：GitCode 地址可复制；
- **环境准备指南**：开发者模式与非应用市场扩展程序的系统设置教程（分步说明 + 直达设置按钮），供排障"装不了/命令找不到"时查阅。

## 4. 页面状态矩阵

每个数据加载页面覆盖四态：

| 状态 | 要求 |
|---|---|
| 加载中 | 骨架屏/进度指示，禁止白屏 |
| 空 | 说明文案 + 行动按钮（重新加载/去安装/去配置源） |
| 加载失败 | 错误摘要 + 重试 + 复制错误详情；区分网络失败/服务不可用/依赖缺失 |
| 离线降级 | 使用本地缓存，明确标识"缓存数据" |

文本类内容（命令、路径、报错、配置项）单击/长按复制；破坏性操作二次确认并列明影响范围；含编辑的页面未保存状态可见。

## 附录 B：产品边界

- 不做命令手册、代码片段类工具集——产品定位是环境管理；
- 不做 Conan 包上传——面向使用者而非贡献者；
- 环境前置门为提醒模式：系统级检测通道（开发者模式状态查询）在当前系统版本上不可用，应用不依据检测结果拦截功能，只做引导提示。
