# DevBox UI 设计规范

> 基线：v2.0.0。本文档定义 DevBox 的视觉体系、组件体系与交互模式，供 UI 实现与后续设计协作对齐。

## 1. 设计原则

面向开发者的工具类应用：

1. **过程可见**：长任务分步展示进度，始终可取消；
2. **一切可复制**：命令、报错、路径提供一键/长按复制——开发者最终要在终端里工作；
3. **信息密度优先**：专业用户可承受较高密度，避免过度留白；
4. **可预期**：破坏性操作必须二次确认并说明影响范围；未保存状态可见；
5. **错误友好**：报错附原因与建议动作（重试/复制/去体检）；
6. **模块同构**：八个语言页、三类包管理页交互模式一致——学会一个就会用所有。

## 2. 视觉体系

### 2.1 主题模式

深色（默认）与浅色双模式，顶栏滑块切换，即时生效并持久化。所有颜色经 `DevTheme` token 引用，禁止页面硬编码色值；组件以 `@StorageProp('themeMode')` 为响应锚，主题切换时自动重渲染。

### 2.2 色彩 token

中性色为 zinc 单色系阶，两套调色板（DarkPalette / LightPalette）按语义映射：

| 语义 | 深色值 | 浅色值 | 用途 |
|---|---|---|---|
| BG | `#1E1E1E` | `#F4F4F5` | 页面背景 |
| BG_PANEL | `#2A2A2A` | `#FFFFFF` | 卡片/侧栏/输入框 |
| BG_ELEVATED | `#3E3E3E` | `#E4E4E7` | 弹窗/表头/次级面板 |
| BG_HOVER | `#404040` | `#D4D4D8` | 悬停反馈 |
| BORDER | `#4A4A4A` | `#C4C4CC` | 常规描边 |
| BORDER_STRONG | `#555555` | `#71717A` | 强调描边 |
| TEXT_PRIMARY | `#FFFFFF` | `#18181B` | 主文本 |
| TEXT_SECONDARY | `#C8C8C8` | `#3F3F46` | 次文本 |
| TEXT_TERTIARY / TEXT_MUTED | `#9A9A9A` | `#64646B` | 辅助文本（对比度满足 WCAG AA） |
| ACCENT_SELECT | `#FF7A00` | `#EA580C` | 选中态强调（橙） |
| ACCENT_ACTION（PRIMARY） | `#0B6FCC` | `#2563EB` | 主操作按钮 |
| SUCCESS | `#22C55E` | `#16A34A` | 成功/正常 |
| WARNING | `#FACC15` | `#A16207` | 警告 |
| DANGER | `#F87171` | `#DC2626` | 危险/错误 |

每个语义色配套 `*_SOFT` 半透明底色 token（用于选中底、状态底），禁止自行拼 rgba。

状态色语义全局统一：绿=正常、黄=警告、红=异常、中性=未安装。

### 2.3 终端色板

命令输出区使用固定六色（不随主题切换）：背景 `#181818`/`#18181B`、前景 `#C8C8C8`、绿 `#22C55E`、橙 `#FB923C`、青 `#38BDF8`、红 `#F87171`。命令/STDOUT/STDERR/成功/错误按行分类着色。

### 2.4 字号

正文 12px 基准（工具类应用的高密度取向）：

| token | 值 | 用途 |
|---|---|---|
| FS_H1 | 16 | 页面标题 |
| FS_H2 | 13 | 区块标题 |
| FS_H3 / FS_BODY | 12 | 小标题 / 正文 |
| FS_LABEL / FS_CAPTION / FS_BADGE | 11 | 标签 / 说明 / 徽章 |
| FS_STAT | 20 | 统计数字 |

### 2.5 圆角与结构尺寸

| token | 值 | 用途 |
|---|---|---|
| RADIUS_XS / SM / MD / LG | 2 / 4 / 6 / 8 | 卡片与控件的圆角阶 |
| RADIUS_FULL | 999 | 胶囊/圆形 |
| SIDEBAR_WIDTH | 248 | 侧栏固定宽 |

无投影无边框卡为基准形态；弹窗阴影经 `DIALOG_SHADOW_COLOR` token。

## 3. 布局

- **整体结构**：左侧固定侧栏（248px）+ 右侧内容区；内容区顶部为操作行（页面标题 + 顶栏按钮组），其下为页面主体；
- **顶栏按钮**：MCP 状态胶囊、任务队列（角标）、手动刷新、主题滑块，统一 32px 图标按钮规格、10px 间距，右侧避让系统窗口三键（`getTitleButtonRect` 实测 + 安全间距）；
- **Tab 结构**：页面内 Tab 用分段式（DevSegmentTabs，下划线样式），搜索框位于 Tab 下方与工具页同位同款；
- **列表分页**：自绘分页控件（黑白基调 + 箭头按钮 + 页码，`minWidth` 自适应），固定行高 + `.clip` 防行高抖动；
- **窄窗口**：800×600 最小窗宽下布局降级，双栏退化为单栏；
- **键盘导航**：侧栏项与页面控件 focusable，Enter 激活（300ms 防抖抑制按键重复），方向键移动焦点。

## 4. 组件体系

页面层不自绘基础控件，统一使用 `common/component.ets` 的 Dev* 组件库：

| 组件 | 用途 |
|---|---|
| DevSideNav / DevPageHeader / DevSection / DevSectionTitle | 骨架：侧栏、页头、分区 |
| DevCard / DevModuleCard / DevKVRow / DevChip | 信息展示：卡片、键值行、状态芯片 |
| DevBtn / DevInput / DevSegmentTabs / DevPagination | 操作：按钮、输入、分段 Tab、分页 |
| DevVersionRow / DevPkgRow / DevRowProgress | 列表行：版本行/包行/行内进度（两行视觉共用同一进度组件） |
| DevProgressSteps | 安装分步进度 |
| DevTerm / DevCmdLine | 终端输出块 / 单行命令展示（可复制） |
| DevEmpty / DevStatusDot / DevArea | 空态、状态点、文本区 |
| DevDialogPanel + CustomDialog 系 | 弹窗容器（标题栏 + 分割线 + 内容区骨架） |
| DevToast / DevConfirm | 全局提示 / 二次确认 |

表单类控件（下拉、选择器）基于 IBest-UI-V2 组件库定制。新增页面优先复用上述组件；需求无法满足时先在组件库扩展，再考虑页面内自绘。

组件级约定：

- 组件 prop 命名避开保留字（如 `onClick`）；
- `@Builder` 按值传参不具响应式——交互式详情区块用无参 `@Builder` + 组件状态；
- 行内进度等高频更新组件的 key 只表身份不表状态（进度值进 key 会销毁重建、打断过渡动画）。

## 5. 交互模式

### 5.1 长任务

分步进度（步骤名 + 权重推进）+ 行内进度条 + 取消按钮；失败定位步骤、给原因、可重试可复制；完成后 toast + 下一步引导。下载支持断点续传。任务进三级队列（顶栏角标 + 队列面板可视）。

### 5.2 状态四态

每页覆盖：加载中（骨架屏）、空态（文案 + 行动按钮）、错误（摘要 + 重试 + 复制详情）、离线降级（缓存数据标识）。

### 5.3 复制与确认

文本类内容单击/长按复制 + toast 反馈；破坏性操作（卸载/删除变量/清缓存/切源）二次确认弹窗，列明影响范围；含编辑的页面（环境变量、镜像配置）未保存守卫。

### 5.4 弹窗

统一弹窗容器：标题栏 + 分割线 + 内容区（可选定高滚动）。协议原文等长文本用折叠区（点击标题行展开/收起，收起态显示 ▸/▾ 指示）。CustomDialog 回调先 close 再 `setTimeout` 执行跳转类动作。

### 5.5 提示与引导

- 首次启动使用提示（可不再提示）；
- 环境准备指南：分步教程文本统一规格（步骤序号 + 正文说明），步骤内按钮直达系统设置；
- 版本切换后固定提示"重开终端生效"。

## 6. 可访问性

- 文本对比度满足 WCAG AA（辅助文本色值经审计校准）；
- 全键盘操作路径可达；
- 焦点态有可见视觉反馈（悬停色 + 焦点描边）。
