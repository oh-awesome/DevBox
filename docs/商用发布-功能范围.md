# 商用发布功能范围

商用发布版本的功能裁剪范围。以下功能界面不显示（代码完整保留，后续版本按开关恢复）：

## 屏蔽页面（侧边栏不出现）
- **Ruby 整页**
- **Bun 整页**

## 屏蔽 Tab（页面只保留「运行时」tab）
- Java：包与工具、项目、设置（Maven/Gradle 规划卡片）
- Rust：包与工具、项目、设置
- Lua：包与工具、项目、设置
- Perl：包与工具、项目、设置
- Go：包与工具、项目、设置
- PHP：包与工具、项目、设置（Composer/扩展管理/php.ini 规划卡片）

## 屏蔽 Tab（页面保留 运行时/镜像管理/包管理）
- Python：项目管理（tab 3）
- Node.js：项目管理（tab 3）

## 实现方式：集中开关（utils/FeatureScope.ets）

裁剪全部走渲染层（tab/侧边栏不渲染），页面代码与数据完整保留：

| 开关 | 控制 | 当前值 |
|---|---|---|
| `ECO_TABS` | java/rust/lua/perl/go/php 的 包与工具/项目/设置 tab | false |
| `PROJECT_TAB` | python/node 的项目管理 tab | false |
| `RUBY_BUN` | Ruby/Bun 侧边栏入口与整页 | false |

各 `*_manager.ets` 的 `tabLabels` / `component.ets` langItems() 按开关取值；
`LangRuntimePage` 单 tab 时不渲染 tab 行。

## 恢复指南（功能筹备完成上线时）

1. `utils/FeatureScope.ets` 把对应开关改 `true`（一行一个，可单独恢复）
2. 若恢复 Ruby/Bun：`test/ui_automation/templates/meta.json` 加回 sidebar_Ruby/sidebar_Bun 条目
   （模板 png 仍在 templates/ 目录），`gen_templates.py` SIDEBAR_ITEMS 同步——冒烟回到 15 页
3. 构建、装机即可——无其他散落裁剪点
