# 反馈提交接口

DevBox 应用内反馈弹窗的提交通道：将用户反馈创建为社区（GitCode）公开 Issue。

## 一、接口定义

| 项 | 值 |
|---|---|
| 接口地址 | `https://sd8f60kr13dl1693i3lcg.apigateway-cn-beijing.volceapi.com/` |
| 请求方式 | `POST` |
| 数据格式 | `Content-Type: application/json` |
| 跨域 | 已全局开启 CORS |

## 二、请求参数（Body JSON）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| repo | string | 是 | 仓库名称，固定 `DevBox`；对接同账号其他仓库时改此字段 |
| title | string | 是 | Issue 标题（反馈类型 + 标题拼接） |
| content | string | 是 | Issue 正文（描述 + 诊断信息） |

请求示例：

```json
{
  "repo": "DevBox",
  "title": "【Bug】编辑器打开大文件卡顿",
  "content": "版本 v2.0.0，步骤：……"
}
```

## 三、返回参数

成功（code = 0）：

```json
{
  "code": 0,
  "msg": "反馈成功！",
  "issue_url": "https://gitcode.com/OpenHarmonyPCDeveloper/DevBox/issues/4065933"
}
```

| 字段 | 说明 |
|---|---|
| code | 0 = 成功，-1 = 失败 |
| msg | 状态描述 |
| issue_url | 新建 Issue 地址，应用内以可点击链接展示 |

失败（code = -1）：`{"code":-1,"msg":"缺少参数：repo"}` 或 `{"code":-1,"msg":"服务异常：xxx"}`。

## 四、应用侧调用

调用点：`pages/Index.ets` 反馈弹窗提交（常量 `FEEDBACK_API`），使用 `@kit.NetworkKit` 的 `http` 模块发起请求。成功后弹窗内展示 issue_url 链接（openUrl 打开 + 一键复制）；失败提示错误原因并保留已填内容。

提交前的隐私声明（UI 固定展示）：反馈将发布到社区公开 Issue，所有人均可见，请勿包含个人敏感信息。

## 五、运维说明

- 计费：按量计费，闲时无请求无费用；
- 稳定性：偶发网络波动可重试，应用侧已做错误提示兜底。
